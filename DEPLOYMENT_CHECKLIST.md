# EthnoKG: Render Deployment Checklist

Use this checklist before, during, and after deploying EthnoKG to Render.

---

## 1. Pre-Deployment Codebase Verification (Local)

- [x] **Backend Dependency Test**: Python dependencies installed (`fastapi`, `uvicorn`, `psycopg2-binary`, `alembic`, `pypdf`, `networkx`).
- [x] **Backend Unit & Integration Tests**: All test suites in `backend/tests` passing (`pytest`).
- [x] **NLP Extraction Evaluation**: Gold-standard evaluation passed with 94%+ precision (`scripts/run_evaluation.py`).
- [x] **Production Readiness Verification**: All 12 pre-deployment checks passed (`scripts/test_deployment_readiness.py`).
- [x] **Database Migrations Configured**: Alembic initialized with migration files in `backend/alembic/versions`.
- [x] **PostgreSQL Normalization**: `backend/app/core/config.py` converts `postgres://` to `postgresql://`.
- [x] **Database Connection Pooling**: `pool_pre_ping=True` and `pool_recycle=300` configured in `database.py`.
- [x] **Health Check Endpoints**: `/api/health` and `/healthz` verify database connectivity.
- [x] **Frontend Production Build**: `npm run build` generates optimized bundle in `frontend/dist`.
- [x] **Frontend Static Server**: `serve -s dist -l $PORT` configured for SPA routing.
- [x] **API Base URL Configurable**: `VITE_API_URL` injected into frontend API client.
- [x] **CORS Configuration**: Handles localhost development and all `*.onrender.com` production origins.
- [x] **Version Specifications**: `.python-version` (3.11.10) and `.node-version` (22.12.0) defined.
- [x] **Security Sanitation**: `.gitignore` active; zero API keys, passwords, or secrets committed.

---

## 2. Render Blueprint & Infrastructure Setup

- [ ] **GitHub Repository Pushed**: Code committed and pushed to `main` branch.
- [ ] **Render Blueprint Created**: Created new Blueprint in Render connected to the repository.
- [ ] **Render PostgreSQL (`ethnokg-db`)**:
  - [ ] Name: `ethnokg-db`
  - [ ] Database: `ethnokg`
  - [ ] User: `ethnokg_user`
  - [ ] Region: Match backend region (e.g. `Oregon`)
- [ ] **Backend Web Service (`ethnokg-backend`)**:
  - [ ] Root Directory: `backend`
  - [ ] Runtime: `Python`
  - [ ] Build Command: `pip install -r requirements.txt && alembic upgrade head`
  - [ ] Start Command: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
  - [ ] Health Check: `/api/health`
  - [ ] Environment Variables:
    - [ ] `DATABASE_URL`: Linked from `ethnokg-db`
    - [ ] `SECRET_KEY`: Generated by Render
    - [ ] `ENVIRONMENT`: `production`
    - [ ] `DEFAULT_CONFIDENCE_THRESHOLD`: `0.75`
    - [ ] `FRONTEND_URL`: Set to frontend service URL
    - [ ] `GEMINI_API_KEY` / `OPENAI_API_KEY`: Configured if using cloud LLM fallback
- [ ] **Frontend Web Service (`ethnokg-frontend`)**:
  - [ ] Root Directory: `frontend`
  - [ ] Runtime: `Node`
  - [ ] Build Command: `npm install && npm run build`
  - [ ] Start Command: `npm run start`
  - [ ] Environment Variables:
    - [ ] `NODE_VERSION`: `22.12.0`
    - [ ] `VITE_API_URL`: Set to backend service URL (`https://ethnokg-backend.onrender.com`)

---

## 3. Post-Deployment Verification (Live Service)

- [ ] **Backend Health Check**: `https://ethnokg-backend.onrender.com/api/health` returns status `healthy` and database `connected`.
- [ ] **Interactive API Docs**: `https://ethnokg-backend.onrender.com/docs` loads OpenAPI schema.
- [ ] **Frontend Application Root**: `https://ethnokg-frontend.onrender.com` loads without JavaScript console errors.
- [ ] **Research Dashboard**: Recharts charts display live entity counts and evidence tier distribution from database.
- [ ] **Plant Intelligence**: Search for `Artemisia annua` and verify botanical profile modal opens with correct taxonomic authority.
- [ ] **Cytoscape Knowledge Graph**: Nodes and edges render on interactive canvas with physics layout and node click inspection.
- [ ] **Literature Mining**: Upload a sample PDF or enter raw text and verify 12-stage extraction completes.
- [ ] **Human Verification Workflow**: Approve or reject a pending relationship and confirm verification status updates in real time.
- [ ] **RAG Research Assistant**: Submit query and confirm answer includes cited literature DOI and non-medical research disclaimer.
- [ ] **Reverse Pharmacology Discovery Radar**: Verify candidate ranking and cross-cultural convergence scores.
- [ ] **Direct Route Refresh**: Refreshing on any view (e.g., direct navigation) returns index.html without 404 errors.
